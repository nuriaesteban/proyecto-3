Katas de Python

Descripción del proyecto

Este repositorio contiene una colección de ejercicios prácticos (Katas) desarrollados en Python con el objetivo de mejorar la lógica de programación, aprender a trabajar con estructuras de datos y reforzar los fundamentos del lenguaje.

Los ejercicios están planteados de forma progresiva, utilizando funciones, listas, cadenas de texto, funciones lambda, condicionales , manejo de excepciones y clases.

Cada kata incluye:

Enunciado del ejercicio.

Solución desarrollada en Python.

Docstring explicativo.

Ejemplos de ejecución.

Objetivos

Practicar la sintaxis de Python.

Mejorar la lógica y resolución de problemas.

Aprender a crear y utilizar funciones.

Trabajar con listas y cadenas de texto.

Comprender el funcionamiento de las funciones lambda, map y reduce.

Utilizar condicionales y estructuras de control.

Aprender a gestionar excepciones.

Escribir código limpio y legible

Katas realizadas

1. Condicionales

Trabajar con estructuras de decisión para controlar el flujo de ejecución de un programa.

if

elif

else

Operadores de comparación.

Operadores lógicos (and, or, not).

Condicionales anidados.

2. Bucles y estructuras de repetición

Aprender a repetir instrucciones y recorrer diferentes estructuras de datos.

Bucle for.

Bucle while.

Función range().

break y continue.

Recorrido de listas y diccionarios.

Bucles anidados.

3. Funciones

Crear funciones reutilizables para organizar y simplificar el código.

Definición de funciones (def).

Parámetros y argumentos.

return.

Funciones lambda, map

Importar  y utilizar reduce

Funciones con parámetros opcionales.

Docstrings.

Funciones integradas de Python.

4. Clases y programación orientada a objetos (POO)

Introducir los conceptos fundamentales de la programación orientada a objetos mediante la creación de clases y objetos.

Definición de clases (class).

Creación de objetos.

Atributos y métodos.

Constructor __init__().

Parámetro self.

Encapsulamiento.

Herencia.

Polimorfismo.

5. Estructuras de datos

Aprender a almacenar, organizar y manipular información.

Listas.

Tuplas.

Conjuntos (set).

Diccionarios.

Comprensión de listas (List Comprehension).

6. Manipulación de cadenas de texto

Trabajar con textos y aprender a transformarlos y analizarlos.

upper() y lower().

replace().

split() y join().

strip().

Slicing.

Formateo de cadenas con f-strings

Tecnologías utilizadas

Lenguaje: Python 3.

Editor: Visual Studio Code.

Control de versiones: Git.

Repositorio: GitHub.

Aprendizajes

A través de estas katas se trabajan conceptos fundamentales de Python:

Definición y llamada de funciones.

Uso de parámetros y valores de retorno.

Funciones anónimas (lambda).

Funciones integradas (map(), sorted(), len()).

Manipulación de listas y diccionarios.

Manipulación de cadenas de texto.

Condicionales (if, else).

Gestión de excepciones.

Documentación mediante docstrings.
